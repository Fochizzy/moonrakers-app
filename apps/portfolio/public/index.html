About

Why I know where AI fits.

Since 2018 I've been Manager of Accreditation at Social Current (formerly the Council on Accreditation), running accreditation for the Public Agency, Opioid Treatment and Child & Youth Development business lines — supervising a team of coordinators, owning the budget for two of those lines, and helping update the child welfare standards themselves. Before that, six years in foster care at MercyFirst and Forestdale as a caseworker, supervisor and advocacy liaison. I still review case records part-time at Graham Windham to stay close to practice.

Plenty of people can build a tool. Far fewer have sat in the PQI meeting, run the case record review and walked an agency through accreditation — and can therefore tell the difference between software that takes work off the table and one more system nobody updates. That combination is hard to hire for.

And not only on side projects. At Social Current I spotted where AI could fit in my own department, made the case for it, and had the proposal approved. Same judgment, applied inside an organization rather than to a weekend build — and it had to survive the people who would live with the result.

Claude Code and Codex closed the last gap. Knowing where it fits used to end at a recommendation; now it ends at something working. And reviewing work against a standard was already the day job — reading an agent's diff is the same instinct pointed at a different artifact.

Which is why a public standards library leads this page, ahead of the board game companions. Same method throughout; the difference on that one is that I already knew the standards by heart.

Method

How these actually get built

I don't advise on tools I haven't used in anger. The agents write most of the code; that only works because everything around the writing is tight — and reviewing the diff is the real job.

Spec before code

Decide the product, the data model and what "done" means first. A vague prompt produces a vague codebase, fast.

Agents implement

Codex and Claude Code do the typing — features, refactors, test suites — working against the repo's own conventions.

Review is the work

Every diff gets read. Typecheck, unit tests, lint and Playwright runs gate the merge, not vibes.

Ship to the edge

wrangler deploy and it's live worldwide. No VPS, no container, no 3am pager.
